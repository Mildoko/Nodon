# T04 / T05 浏览器工作台验证说明

当前实现入口是实际产品根的 `src/host/web-server.ts`，静态资源是 `src/adapters/index.html`、`app.js`、`styles.css`。暂存目录只用于交付源文件，不能作为运行根。未复用旧 `06` 设计原型或其状态机。

## 单一状态所有者

- Node `ProjectStore / CommandQueue / RunSession / CandidateManager / AiAuthority` 持有作品、命令、游戏状态、候选与授权。
- 浏览器仅持有服务器只读快照、未提交表单、视觉来源、选中事件 ID、按键集合和私有网络 lease。没有本地作品副本、碰撞、计分、胜负判断或存储。
- `connectionId / csrfToken` 仅在 JS 闭包内；SSE 通过 fetch 请求头连接，无 URL 参数、DOM、日志或 localStorage 写入。
- 页面明确标记输入来源 `machine_browser_input / automation_test`；候选明确标记 `controlled_fixture`，手工构造且不是真实模型输出。

## 已接线流程

1. 页面进入：建立新 session + fetch SSE，250ms 心跳。UI 明示仅内存、刷新保留服务器作品并暂停、重启恢复初态。规则、可玩性、数量和预算完全显示 Node `derived`。
2. 修改：选一个命令 → 保留输入 → Node 预览 → 明确确认一次命令或取消；增加、删除、复制非玩家物件、移动精确坐标、规则、主题、文本及一次撤销均走同一路由。坐标步长与参数范围以 Node 最终校验为准。
3. 试玩：按钮明确开始或继续前先请求画布聚焦；只在画布为 activeElement 且来源为正式试玩时接收 Arrow/WASD。每次方向请求保留两个 signed 分量与 `clientSentAt:Date.now()`，时间戳只作审计，不驱动模拟。失焦、隐藏、断网清键；返回/重连不自动 resume。ended/fault/invalidated 不显示可继续资格。
4. 来源：当前作品 / 正式试玩 / 候选试跑明确切换；没有该来源快照时显示空画面，不把其他来源冒充为该 run。正式事件列表独立标明来源，选择会由 Node 暂停并返回真实 `observe` 前因状态、版本、采样阶段及 actualValues。
5. 候选：同页成人实验权限（非身份认证）→ 从目标/速度/配色构造 1–3 项白名单操作 → base/hash/操作差异 → Node Runtime 验证 → 单独候选画布 → 明确确认或取消。资格按钮直接读取 Node `canTrial / canConfirm`；主题仅静态验证明确写出不适用 Runtime。公开展示实际覆盖与未覆盖，不把程序通过称为真人通关。
6. 取消与撤销：运行验证期间，取消候选、撤销权限、关闭候选能力仍可发送；是否提交由共享队列的真实 gate 决定。其他重复命令等待原请求完成。过期/撤销/同 build 资格均取 Node 快照，不靠浏览器派生。
7. 断网：醒目 banner、停止输入、禁写、保留表单、手动重连；请求结果未知时保留同一 command/request/preview 标识供安全重试。取消待重试只撤销本地重试意图，明确提示服务器是否已接收仍以快照为准。
8. 受控场景：必须勾选明确重置后才能切换服务器现有 catalog。验证模式才显示“模拟连接中断”，不会冒充自然网络故障。
9. 服务实例与构建：跨重连比较公开 `serverInstanceId`，同实例说明保留当前内存作品；实例变化展示持续“服务已重启、回受控初态”提示，未提交表单仍保留。`buildStatus` 非 ready 时禁用试玩启动/继续及候选提交/验证/确认，展示需重启或构建不可用提示。候选 `eligibilityError` 单独展示，历史 passed 不冒充当前资格。
10. 真实证据：`/api/evidence` 仅选择 formal 或当前 candidateId，不接受任意路径。返回 `runPath / proofPath / exportedTick / currentTick / existing` 仅用 textContent 显示；不自动打开、读取或回调该路径。正式导出会暂停；重复导出明确显示原包与原导出 tick。失败保留作品与表单，提供重试/取消；服务实例或正式 run 变化后拒绝重放旧导出，以免错导另一轮。页面明确“机器证据导出不是作品保存”，HTTP User-Agent 未认证、不是人工操作证明。主题静态候选无 Runtime 包时原样显示 null，不伪造覆盖。

## 实际浏览器待核验清单

本文件记录实现接线和计划检查，**不是执行证据**。UI 作者仅做 JS 语法检查，未从暂存目录运行服务或浏览器。root 在唯一产品根同步后执行并记录真实浏览器结果。

- 1366×768 / 1920×1080：工作台层次、Canvas 比例、规则预算与关键提交按钮可见或顺畅滚动。
- 1280×720：预览→确认、开始→暂停→明确继续、事件选择、候选流程等关键动作可到达。
- 内置“文字 200%”：根字号实际翻倍，网格重新排列、内容可滚动、不出现文档横向溢出；恢复 100% 可逆。
- 输入框键入 W/A/S/D 与箭头不移动；画布聚焦输入通过 Node 真正推进；blur / visibility / stream loss 后 Node 暂停清键；回到页面不自动继续。
- 原作品编辑使正式 run invalidated；主题/文本编辑不伪造新运行外观；事件查看不增加 revision。
- Node 预览结果与精确坐标/参数一致；取消无 revision；确认一次 revision +1；重复请求不重复提交；空值、范围和预算拒绝显示真实 Node 错误。
- 受控候选检查、真实验证、试跑快照、应用/拒绝/取消/过期/撤权限/关闭能力与重复确认按钮状态一致。
- 断网 banner、表单保留、重连不自动恢复、原请求安全重试；刷新保留服务器 Store；服务重启明确恢复初态。
- 正式/候选证据导出返回真实 Node 包；重复导出原 tick 不被新 tick 覆盖。错误显示与重试/取消可用，取消不清作品或表单。HTTP UA 与机器来源不被标签改写成人工或浏览器认证。

模型版本、费用授权与真实模型出站不由此 UI 修改。本轮没有可点击的真实 AI 请求入口，也未读取或展示密钥。

## 独立 UI 复审后的最小修复

- 导出结果绑定请求发起时的 `serverInstanceId`、正式 `targetRunId`、候选 `targetCandidateId`（来自实际请求体），在界面显式展示。随后服务、run 或候选身份变化时，将原路径与原导出 tick 标成“历史机器证据”，不再称为当前一轮；该只读渲染不清除失败请求、重试状态或表单输入。
- 未勾选的候选字段使用 `disabled` 排除 HTML 原生约束验证，原数值保留；重新勾选后恢复启用及原有 min/max/step 约束。避免未选速度的非法残值阻断仅目标分数候选。
- 本次仅执行 Node 24.21.0 JS 语法检查；真实新构建浏览器回归由 root 重启后执行。
