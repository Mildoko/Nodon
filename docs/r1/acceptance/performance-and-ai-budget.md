## 设备与采样

参考机器只读OS/架构在review/environment-reference.json。未来T00在**同一实际本机**登记型号/内存、OS build、Node24.21.0及npm11.19.0、浏览器精确版本/DPR/电源和后台负载，不能先留空再声称满足性能；增加设备另测，不做未测设备承诺。

用默认起点和18总数上限（1玩家、2守卫、12普通、3特别）、0守卫、合法不可玩草稿四组；计时15/45/120秒及关闭。每个连续run最多7200tick；连续60分钟交错重开、编辑、S03分页、S07状态和焦点失去/隐藏/重连。禁止为了凑时长超出既有run上限。计时关闭时达到run上限按现行预算终止/暂停，不能假造win/timeout。

热身5分钟，后续每10分钟一段；至少1000条输入收据和1000次投影查询。单独记录冷启动/首键各20次；没有样本不能填p95。使用单调时钟；浏览器→Node跨进程延迟依request/receipt往返或校准区间，不能直接相减未经校准的两套时钟。

## 冻结阈值

| 项目 | 判准 | 测法/失败处理 |
|---|---|---|
| thin snapshot | 序列化UTF-8 ≤64KiB；默认10Hz、硬上限20Hz；没有全frames/history/inputs/events | 每响应计bytes；超限报协议错误并保上个有效视图，不静默丢字段 |
| 读投影 | 本机端到端p95≤200ms；Node处理p95≤50ms | 1000次，同ID请求/收据；失败/超时单列并保分母，不只取成功 |
| 订阅连接 | 创作最多3个活动订阅、成人最多1个；每连接1在途+1最新pending | 超额不发行新写权/动态订阅，静态只读说明；已有Node草稿不丢 |
| 事件页 | 默认50、最大100项；每页≤128KiB；UI仅保当前与相邻两页、合计≤300项 | 原始运行只追加证据与UI环形1000分开；旧cursor截断明示 |
| 输入生效 | running且可玩视图聚焦：收到有效方向后≤2个实际模拟tick生效；输入ACK往返p95≤100ms | 三时间点/序号/receiveTick/appliedTick；首键未接收直接失败，不用墙钟按键长度判断 |
| 暂停清键 | blur/hidden/断连命令到Node后下一次可调度tick前清键并paused；20次恢复均不自动续 | 保存队列顺序和终局状态；ended/fault/invalidated不复活 |
| droppedWallTicks | 常规负载每run=0；故意慢渲染/断连场景允许>0但必须记数、明示暂停/退路，不能判常规性能通过 | 每组原run保留wallTick与实际tick；11/2的26不是本次达标结果 |
| 本地保存 | ≤1MiB合法作品，IO起至持久commit ACK p95≤500ms（不含300ms debounce） | 100次含保存中再改；磁盘故障另类必须failed/dirty，拒绝伪saved |
| 首次界面/帧 | 服务ready后S00可操作p95≤2s；试玩帧间隔p95≤33.4ms | 本机20次冷页面；帧日志至少1000，不据SVG或截图判60fps |
| 长run资源 | 5分钟热身后60分钟，Node RSS增长≤64MiB，浏览器JS heap增长≤32MiB；没有采样工具即阻塞该项 | 10分钟一次共7点；说明GC波动，取最后3点中位数减热身3点中位数，热身需5/4/3分钟三点；Node RSS（含storage worker与认证KDF）另≤512MiB、JS heap≤128MiB |
| 证据容量 | 会话内最多8个未归档run；逐tick环节每run≤7200tick、UI事件≤1000；完整审计原件独立流式存档；单run审计包≤16MiB、会话暂存≤128MiB | 达容量先暂停、提供显式归档/清理/导出，不静默销毁；I/O失败保有限内存并阻止新run，现run安全暂停 |

p95采用nearest-rank ceil(0.95*n)；超时按设定超时值计延迟并单列，错误不能消失。性能阈值不证明玩法可解或教学效果。静态S03页容量不等于原始证据只保1000条。

T11/T12只开发集和专项；T16在最终代码/提示/工具/目录/build/artifact签版后按manifest中ID顺序、每例repeat1再repeat2，独立运行冻结20一次；T17只审原件。供应商访问失败不换题/删样本。模型p95≤15秒（初次send至可读合法回答/候选，必要校验试跑计入）；3秒进度，20秒前端停止等待/取消，费用未知保预留。若20秒前端截止影响p95，超时按≥20秒计，不记作0或不适用。传输重试须沿同一逻辑请求，语义修复单独ID及费用。
