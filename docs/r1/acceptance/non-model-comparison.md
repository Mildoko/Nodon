## 顺序与等价变体

正式参与前记录匿名编号、两个工具经验、参与/发送范围与支持者。采用同一受限作品域，几何镜像variantB（x→960−x）由Node用同校验器创建新身份与hash；规则/数量不变，镜像文件不能被当作已运行证据。镜像移动命令目标坐标也相应转换；无法保持等价时预先声明该对不作时间因果比较，仍收定性反馈。

1. PAIR01 明确改目标与保留奖励：AI先（开发S03目标8）、镜像变体手动后；只比较同任务完成、支持、意图约束、作者判断，不以一次少点击当教育增益。
2. PAIR02 模糊方向：程序帮助先、AI后（开发A01）。两侧都允许看规则含义和选择方向；记录保留约束、所需提示、拒绝/退出，不能只看参数最终相同。
3. PAIR03 基于事件排错：AI先（专项SP03真实@3最小主动选中链）、手动事件/规则帮助后。两个变体各自产生真实run，不能捏造等价caught事件；若一边未产生匹配事实，只作观察/未知退路，不给配对速度结论。
4. PAIR04 数量需求边界：手动帮助先、AI后（开发U01）。AI只解释/定位手动物件面板，无额外写权；两侧实际增减仍由人决定。

只在上述计划来源任务实时采集AI侧请求，复用其逻辑/attempt身份，不为对照新发未授权请求、不回放旧响应冒充实时交错。后一次已有学习/顺序影响必须记录；成人代理不是儿童效果。每对人工侧不向模型外发、不给实施者打开sealed20调试。
